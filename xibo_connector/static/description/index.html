Setup in 3 minutes

  1. In Xibo: Administration → Applications → Add Application.
  2. Enable Client Credentials, scope all, set Owner to your super-admin.
  3. In Odoo: Xibo Signage → Configuration → Servers → New server with URL + creds.
  4. Click Test Connection. The badge turns green.
  5. Click Sync All: displays, groups, layouts, datasets and library metadata appear.
  6. Upload media from Media Library or use Quick Display for instant broadcasts.
